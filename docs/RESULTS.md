# Example simulation results

Generated by `npm run experiments -- --runs 40 --seed 2026` on 2026-11-07.
Each configuration uses the same 40 seeds (common random numbers) unless stated otherwise; sensitivity, occupancy, barrier and staffing sweeps use the first 20.
All times are SIMULATED under the documented assumptions (docs/PARAMETERS.md); they are not calibrated predictions and do not prove regulatory compliance.

T = total evacuation time (last person leaves the building). Unfinished runs count as failing the 180 s benchmark. Raw data: `results/experiments/`.
